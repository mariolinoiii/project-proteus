# Project Proteus

This project uses SAR imagery and ESA WorldCover data to detect and classify oil spills.

## Colab Notebook

Open the main notebook here:

[ProteusSegNet.ipynb](ProteusSegNet.ipynb)

## How to run

1. Open the notebook in Google Colab.
2. Connect to a runtime.
3. Upload the required SAR and WorldCover GeoTIFF files.
4. Run the cells from top to bottom.
